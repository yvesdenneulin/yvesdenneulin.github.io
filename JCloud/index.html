Manipulations de l'après-midi

Pour vous inscrire aux manipulations AWS de l'après-midi envoyez moi un mail avec votre adresse @grenoble-inp.org.

Vous devez avoir d'abord ouvert votre compte temporaire AWS en répondant au mail reçu. Suivez ensuite attentivement la documentation pour démarrer votre laboratoire AWS qui vous donne accès à une version partielle de la console AWS. Cette dernière s'ouvre dans une fenêtre qui peut avoir été filtrée par votre gestionnaire de pop-ups.

Les services de base en IaaS proposés par AWS sont :

  • S3 pour le stockage de fichier dans des buckets
    • ,
  • EC2 pour lancer des machines virtuelles.

Pour découvrir comment cela fonctionne et les contraintes d'accès et de sécurité associées, une fois que vous avez accédé à la console vous pouvez réaliser les opérations suivantes :

  1. créer un bucket avec S3
  2. ajouter un fichier quelconque dans ce bucket
  3. créer une machine virtuelle EC2 Linux
    1. vous connecter dessus avec ssh
    2. récupérer et afficher le fichier uploadé
    3. bonus : explorer la machine créée, en essayer d’autres (/proc/cpuinfo, /proc/meminfo, df -h, …)

Vous pouvez aussi faire, par exemple, les tutoriels suivants :

  • Démarrer une machine virtuelle,
  • Héberger un site web statique avec S3,
  • Héberger un site web statique,
  • Déployer une pile LAMP sur une machine virtuelle.
